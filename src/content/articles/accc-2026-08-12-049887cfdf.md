## Unit Pricing Rules in Australia

In Australia, there are rules about who must display unit prices for groceries, where they must be displayed, how they should be displayed, and for what products. These rules are set by the Australian Competition and Consumer Commission (ACCC).

## How the ACCC Helps

The ACCC provides information on how the unit pricing code works. You can check the ACCC website accc.gov.au for more details. The unit price helps you find the best value for your money.

## Reporting an Issue

If you have an issue with unit pricing, you can report it to the ACCC. Anyone can make a report to the ACCC about an issue with unit pricing.
